## 当前实际运行的 E2E

文件：`tests/e2e/visualization.spec.ts`。

1. 网格稳定性：选中示例 1，确认 3×3 共 9 格；步进时单元格 DOM 节点稳定；后续 10 步检查 viewBox、SVG 边界与格数保持不变，图例和解说可见。
2. 无障碍动效与配色：设置 `prefers-reduced-motion: reduce`，确认 CSS 动画时长归零且页面无禁用紫色 token。

完整执行：`npm run test:e2e`。该命令目前只运行 2 条用例，不能表述为 15 条矩阵通过。
