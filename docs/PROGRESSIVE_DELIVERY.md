## 本地开发

- Node.js + npm；安装依赖：`npm ci`
- 开发：`npm run dev`（Vite 端口 40889）
- 首次浏览器测试：`npm run test:e2e:install`

## 交付约束

后续改动依照 `QUALITY_GATE.md` 先跑门禁，再在 `ACCEPTANCE_CHECKLIST.md` 与 `ACCEPTANCE_REPORT_TEMPLATE.md` 留存事实证据；任何失败必须记录根因、修复与复测结果。
